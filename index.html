Principios y Reglas de Negocio

Invariantes innegociables establecidas en la constitución del proyecto.

RN-1 · Inventario de Ejemplares

Los ejemplares disponibles siempre se mantienen entre 0 y el total. Modificar el total ajusta los disponibles en la misma diferencia y nunca permite valores negativos.

RN-2 · Plazos y Límites

El plazo máximo de préstamo es de 14 días calendario. Un socio nunca puede acumular más de 3 libros sin devolver de forma simultánea.

RN-3 · Bloqueo por Mora

Cualquier socio con al menos una línea de préstamo vencida queda inhabilitado automáticamente para solicitar nuevos libros hasta ponerse al día.

RN-4 · Metadatos Congelados

El título, ISBN y categoría del libro se congelan en la línea de préstamo en el instante exacto de la operación; no sufren modificaciones si el catálogo cambia luego.

Arquitectura Modular SDD

Separación de responsabilidades distribuidas en 6 repositorios.

Backend (API) · PHP Laravel

API RESTful con autenticación JWT, migraciones con UUID, manejo de transacciones atómicas con bloqueo pesimista y envoltura de error única.

Frontend (App) · React SPA

Interfaz de usuario interactiva y responsiva con gestión de catálogo, registro dinámico de préstamos y reportes gráficos.

Infraestructura · Docker & PostgreSQL 16

Contenedor de base de datos aislado que garantiza un motor vacío al arrancar y delega el esquema a las migraciones.

Herramienta (Tool) · Siembra por API

Script que consume la API para poblar libros, socios y préstamos de prueba sin acceder directamente a sentencias SQL.
